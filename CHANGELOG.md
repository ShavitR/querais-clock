# Changelog

## 1.2.0 — Detailed collection

- Rebuilt all four objects with hollow case sections, material joints, recessed fasteners and meaningful reverse-side detail.
- Added Atelier's exhibition movement, pierced wheels, bridges, ruby bearings, balance and hairspring; independent decorative motion respects reduced motion.
- Added Slate electronics and knurled controls, Relay card stacks and cassette hardware, and Signal optical cells, fins and service components.
- Added normal-driven studio reflections, bounded native mesh batches, a two-object cache and a streaming typed mesh loader.
- Corrected Blender parent-pivot placement and native segment depth rendering. Expanded native screenshots and behavioral checks.
- Included original editable Blender source, optimized GLBs, real Cycles previews and documented design research.

## 1.1.0 — First community release

- Four original 3D clocks: Atelier, Slate, Relay and Signal.
- Flat analog and digital alternatives.
- Crown, orbit, caseback, inspection, glass, turntable and studio lights.
- Themes, finishes, focus, compact and always-on-top modes.
- Timer, stopwatch, alarms, local preferences and tray controls.
- Editable Blender source, GLBs and original artwork.
- 28 passing automated checks and portable Windows x64 release.

See VERIFICATION.md for manual-testing limits and alarm/session behavior.
